# راه‌اندازی سفارش + اعلان بله (برای هر کافه، حدود ۱۰ دقیقه)

1. در بله با @botfather یک ربات بساز و توکن را بگیر.
2. یک Google Sheet جدید بساز → Extensions → Apps Script → محتوای `apps-script/Code.gs` را بچسبان و سه ثابت بالای فایل را پر کن.
3. تابع `testBale` را اجرا کن. اگر نتیجه ok بود ادامه بده (اگر خطا داد، سرور گوگل به بله دسترسی ندارد؛ باید یک ریلی روی هاست ایرانی بگذاری).
4. تابع `setup` را یک‌بار اجرا کن و مجوزها را تأیید کن.
5. Deploy → New deployment → Web app → Execute as: Me، Who has access: Anyone → آدرس `/exec` را کپی کن.
6. در `admin.html` تب «تنظیمات فنی» → آدرس را در «سفارش و اعلان بله» بگذار و منتشر کن.
7. مالک، مدیر و گارسون‌ها در بله به ربات پیام می‌دهند و PIN را می‌فرستند؛ خودکار در شیت Recipients ثبت می‌شوند. برای غیرفعال‌کردن، ستون «فعال» را FALSE کن.
8. QR هر میز: `آدرس-سایت/?t=شماره‌میز`

نکته: ربات بله فقط به کسی که قبلاً به آن پیام داده می‌تواند پیام بدهد، پس ثبت با «شماره تلفن» ممکن نیست؛ ثبت با PIN جایگزین آن است.
